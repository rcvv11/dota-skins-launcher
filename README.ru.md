# Dota Skins Launcher

[English](README.md) | **Русский**

Скинченджер для Dota 2

> ⚠️ **Риски.** В режиме «в памяти» лаунчер внедряет DLL в `dota2.exe`, а для предметов в пустых
> слотах меняет `gameinfo_branchspecific.gi` и `dota.signatures`. Это нарушает правила Steam / Dota 2
> и может привести к блокировке аккаунта (VAC). Используйте на свой страх и риск, лучше на
> отдельном аккаунте. Проверка целостности файлов в Steam возвращает игру к оригиналу.

---

## Возможности

- **Пресеты** предметов для всех героев, общие предметы (курьеры, варды, крипы, башни, эмблемы,
  погода, ландшафт, эффекты карты, HUD, экраны загрузки и т.д.).
- **Выбор в самой Dota.** Можно выбирать предметы в самом клиенте игры.

- **Два режима работы** Через инжект DLL (для возможности менять в самой игре) и обычное изменение vpk.

## Сборка и запуск

### Шаг 1. Установите Rust

1. Скачайте и запустите установщик с сайта <https://rustup.rs> (`rustup-init.exe`).
2. Если установщик предложит поставить Visual Studio, выберите пункт
   **3) Don't install the prerequisites** — проекту она не нужна. Дальше нажмите `Enter`:
   подойдут настройки по умолчанию.
3. Откройте новое окно PowerShell и выполните:

   ```powershell
   rustup default stable-x86_64-pc-windows-gnu
   ```

### Шаг 2. Установите компилятор C++ (MinGW-w64)

Он нужен, чтобы собрать `changer.dll`.

1. Скачайте `w64devkit-x64-<версия>.7z.exe` со страницы
   <https://github.com/skeeto/w64devkit/releases> и запустите его. Это самораспаковывающийся
   архив: укажите папку `C:\`, и файлы окажутся в `C:\w64devkit`.
2. Добавьте папку `C:\w64devkit\bin` в переменную среды `PATH`:
   «Пуск» → «Изменение системных переменных среды» → «Переменные среды» → `Path` → «Создать».
3. Откройте новое окно PowerShell и проверьте: `g++ --version` должен вывести версию.

### Шаг 3. Скачайте проект

Кнопка **Code → Download ZIP** на странице репозитория (и распаковать), или через git:

```powershell
git clone <url> dota-skins-launcher
```

### Шаг 4. Соберите

Откройте PowerShell в папке проекта и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт проверит, что Rust и компилятор установлены, соберёт лаунчер и `changer.dll` и сложит
всё в папку `dist\`.

### Шаг 5. Запустите

1. Запустите `dist\dota-skins-launcher.exe`. Он сразу попросит права администратора — они нужны,
   чтобы подключиться к Dota.
2. **При первом запуске** лаунчер сам скачает всё, что ему нужно:
   - каталог предметов (из публичной схемы предметов Valve, около минуты);
   - Source2Viewer-CLI (около 65 МБ) — для 3D-превью, раскрасок и свечений предметов.
   Ход загрузки виден в строке состояния внизу окна.
3. В настройках укажите путь к `dota2.exe`:
   `...\steamapps\common\dota 2 beta\game\bin\win64\dota2.exe`.
4. Нажмите «Запустить Dota 2». Лаунчер запустит игру и подключится к ней.
5. В Dota наведите мышь на карточку предмета и нажмите «ВЫБРАТЬ». Лаунчер должен оставаться
   открытым: нажатия обрабатывает он.

Некоторые вещи вступают в силу только после перезапуска Dota: предметы для пустых слотов
(таблица предметов читается при старте игры), погода и отключение склейки моделей (`autoexec.cfg`).


## Сторонние компоненты

- [ValveResourceFormat / Source2Viewer-CLI](https://github.com/ValveResourceFormat/ValveResourceFormat)
  (MIT) — не входит в репозиторий, лаунчер скачивает его сам.
- [SteamDatabase/GameTracking-Dota2](https://github.com/SteamDatabase/GameTracking-Dota2) и
  [odota/dotaconstants](https://github.com/odota/dotaconstants) — источники данных для gencatalog.
- Dota 2, её модели, эффекты и названия предметов принадлежат Valve Corporation. Проект не связан
  с Valve и не распространяет её файлы.
